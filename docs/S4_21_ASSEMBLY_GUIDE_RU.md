# Сборка Mesh Repeater S4.21

Источник комплектации — [BOM S4.21](../bom/S4_21_COMPONENT_BOM.csv), 172 позиции. Выберите **один** вариант: `NaIon`, `NaIon_NoCold` или `LTO_2S`; используйте его `Fit_*`, `Value_*`, `MPN_*`. Не смешивайте столбцы разных вариантов. DNP на схеме не используется для зачёркивания деталей: комплектность определяется CSV.

В S4.21 удалены SH1 и TP6. Рамки и крышки нет; исторические файлы моделей экрана не являются инструкцией по его установке. [Изменения S4.21](S4_21_ASSEMBLY_DELTA_RU.txt) относятся к текущей схеме и плате.

## Варианты

Для Na-ion R3 = 61,9 кОм, для LTO R3 = 121 кОм; R4 = 100 кОм в обоих случаях. C30 = 12 пФ для Na-ion и 6,8 пФ для LTO. EN TPS63802: R15 = 40,2 кОм для Na-ion и 130 кОм для LTO; R16 = 49,9 кОм. Точные допуски, корпуса и выбранные MPN смотрите в BOM. Неуказанный MPN не заменяется автоматически деталью того же номинала.

Для Na-ion балансиры R47–R54, U8/U9, C58/C59 и J12 не устанавливаются. Для LTO они устанавливаются по CSV, R47/R51 остаются по 2 Ом. Na-ion подключается к J8, LTO — к J12; распиновка обозначена на плате. Проверить полярность и напряжения до подключения аккумулятора.

Na-ion с COLD: R56 = 1,8 Ом и установлены детали термоконтроля. Na-ion без COLD и LTO: R56 = 0 Ом/перемычка, остальные позиции COLD не устанавливаются по выбранному `Fit_*`. R1 = 0,28 Ом во всех вариантах. TH1 — только один датчик: на плате либо выносной у ячейки, не параллельно. Датчик на плате измеряет её локальную температуру; соответствие температуры ячейки требует проверки.

C12 и C52 устанавливаются; C53/C54/C55 по умолчанию пустые. Электрическое прохождение дорожки через посадку C53 сохраняется без установки конденсатора. После R55 = 47 мОм стоят два LC-каскада; R40/R41 = 22 мОм включены последовательно с банками конденсаторов, а не с нагрузкой. Для каждого банка требуется не менее 330 мкФ эффективной ёмкости при 3,3 В.

Добавленный INA219 — U12, шунт R71 = 0,1 Ом, 2512, 1 Вт; его Kelvin-отводы предусмотрены платой. Само наличие INA219 и RTC не означает, что выбранная штатная прошивка уже использует эти функции.

## Nice!Nano, USB и watchdog

Используется аппаратно доработанный Nice!Nano-клон: выход фильтра подключён к 3V3/VCC, аккумулятор не подключается к RAW/BAT модуля, встроенная аккумуляторная USB-зарядка отключена. Для выбранного клона должны быть подтверждены прямое питание и допустимость питания всей платы через его LDO.

При работе от батареи/солнца J11 установлен. **Перед USB снять J11; вернуть его после отключения USB.** Автоматического переключателя источников нет. CR2032 питает часы и не заряжается.

Watchdog регистрирует высокий переход TXEN; примерно через три часа без зарегистрированной передачи выдаёт сброс MCU, после которого прошивка должна переинициализировать модем. Штатное молчание тоже приводит к сбросу. Проверка коротких реальных импульсов и восстановления самого ATtiny не выполнена.

Файлы watchdog сохранены без изменений. Следуйте [его инструкции ISP](../design/watchdog_reference/INTEGRATION_RU.txt): снять R37 перед программированием и вернуть после, J10 только 3,3 В, не подавать питание программатора одновременно с питанием платы. Сначала FLASH, затем предусмотренные fuse; после записи проверить сигнатуру и прочитать настройки обратно. Физическая запись и испытание не подтверждены этими CAD-проверками.

## SMA и опциональный SAW

В HT-RA62 для вывода ANT к SMA предусмотрены R1 = 0 Ом и снятый R2 ветви IPEX — это обозначения **внутри модема**, а не платы. По умолчанию FL1 отсутствует, NT1 представляет собой медную перемычку.

Чтобы установить S869M000S003, отключите питание, разрежьте центральную дорожку под фильтром и проверьте разделение цепей. Фильтр рассчитан на 868–870 МГц и входную мощность не выше +13 dBm; соответствующее ограничение должно быть задано в прошивке. NT1 не покупается как отдельная деталь.

## Сохранённые ограничения прототипа

Балансир с R47/R51 по 2 Ом сохранён по принятому варианту. Ранее рассчитанный угол при 2,80 В требует около 58,35 мА, выше нормируемого режима LMV431; фактический ток вне спецификации не предсказывается. Требуются измерение тока и нагрева. Балансир не является BMS и не компенсирует большой разбаланс при полном токе зарядки.

Независимой защиты OVP нет. При отсутствующем аккумуляторе CN3722 может поднять выход выше рабочего диапазона TPS63802, особенно в LTO-варианте; работа без батареи и её горячее отключение не квалифицированы. EN контролирует сумму напряжений аккумулятора, а не каждую LTO-ячейку отдельно.

Температурные пороги COLD, запуск, переключение тока и допустимость холодной зарядки конкретной ячейки требуют испытаний. Также нужны проверка реального Voc панели (в проекте принято не выше 24 В), эффективной ёмкости MLCC, устойчивости питания, просадок при TX и EMI. Статические проверки подтверждают схему и геометрию, но не являются результатами испытаний изготовленного устройства.
