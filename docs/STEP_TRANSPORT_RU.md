# Передача крупных STEP-файлов

Крупные STEP-экспорты POWER, LOGIC и окончательной сборки публикуются как `.step.gz`. Сжатие сохраняет все исходные байты; геометрия, модели и библиотеки KiCad не меняются. Локальные исходные STEP остаются на месте. Нативные библиотеки `3dmodels` и STEP среднего экрана публикуются в исходном виде.

После скачивания репозитория выполните из каталога Mesh Repeater 2.0:

```powershell
python tools/restore_v2_step_exports.py
```

Достаточно Python 3.11 или новее; модуль KiCad/FreeCAD не требуется. Скрипт сверяет SHA256 каждого gzip, затем SHA256 распакованных байтов и записанного STEP. Восстановленные файлы появляются по исходным путям, поэтому сохранённые экспортные manifests и ссылки на STEP продолжают действовать. Если правильный исходный STEP уже существует, он только проверяется.

Проверка транспорта без записи файлов:

```powershell
python tools/restore_v2_step_exports.py --verify-only
```

Если существующий STEP отличается от сохранённого оригинала, обычный запуск завершится ошибкой, сохранив его. Для сознательной замены такого файла служит `--force`. Контрольные суммы и размеры находятся в [step_transport.json](step_transport.json); исходные экспортные manifests сохраняют свои прежние SHA256.

Для обновления транспортных копий после окончательного экспорта используется `tools/prepare_v2_step_transport.py`; флаг `--include-assembly` добавляет окончательные собранный и разнесённый STEP. Это упаковка экспортов, а не генерация или изменение схемы/платы.
