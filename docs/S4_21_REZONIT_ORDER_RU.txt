Mesh Repeater ver 1.0 — PCB S4.21
Данные для заказа голых плат в «Резонит», 18.10.2026

Загружать файл: Mesh_Repeater_S4_21_Rezonit_Gerber.zip.
Внутри только 9 файлов в корне, без вложенных папок:
  F.Cu / GTL — верхняя медь
  B.Cu / GBL — нижняя медь
  F.Mask / GTS — верхняя паяльная маска
  B.Mask / GBS — нижняя паяльная маска
  F.SilkS / GTO — верхняя маркировка
  B.SilkS / GBO — нижняя маркировка
  Edge.Cuts / GKO — замкнутый контур платы
  PTH.drl — металлизированные отверстия
  NPTH.drl — неметаллизированные отверстия

Формат Gerber: RS-274X. Сверловка: Excellon, миллиметры, десятичный формат.
Оба экспорта используют общий абсолютный ноль (0;0), без зеркалирования Y.
Нижние производственные слои отдельно зеркалировать не нужно.
В заказ не загружать PDF, проект KiCad, чертежи, изображения или Gerber Job.

Ранее согласованные параметры заказа:
  Количество: 5 шт.
  Размер одной платы: 90 x 100 мм, прямоугольник.
  Проводящих слоёв: 2.
  Материал и стандартная готовая толщина: FR4, 1,5 мм.
  Медь: 35 мкм с каждой стороны.
  Паяльная маска и маркировка: с обеих сторон.
  Изготовление: только платы, без монтажа компонентов и трафарета.
  Контур: одиночная плата, без пользовательской панели и V-cut.
  Цвет маски/маркировки и покрытие площадок: выбрать при оформлении заказа.
