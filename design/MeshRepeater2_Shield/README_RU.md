# Mesh Repeater 2.0 — средний экран V2.0-A1

Редактируемый проект: `MeshRepeater2_Shield.kicad_pro`, плата —
`MeshRepeater2_Shield.kicad_pcb`. Размер 90 × 60 мм, толщина CAD 1,52 мм.
В сборке экран поворачивают X180: физическая медная сторона направлена вниз,
к POWER. Верхняя LOGIC установлена компонентами вниз. Рамка SH1 удалена по
решению компоновочного аудита; экран с одной связной областью фольги занимает
её место. Штыри межплатного разъёма проходят через двенадцать отдельных
изолированных отверстий HS1.

Изготовление **одностороннее: только F.Cu**. KiCad 10 сохраняет минимальный
двухслойный контейнер, даже когда `SetCopperLayerCount(1)` сообщает один слой
в памяти. Файл с удалённой записью B.Cu не проходит повторное чтение. Поэтому
для открытия и редактирования сохранён валидный native контейнер; B.Cu пустой,
на нём нет медных площадок, дорожек, зон или надписей. Он не относится к
изготавливаемой меди. Это ограничение инструмента, а не второй слой экрана.

Физический стек задан явно и выдерживает native сохранение/повторное чтение:
F.Mask 0,010 мм → F.Cu 0,035 мм → сердцевина FR4 1,475 мм;
B.Cu и B.Mask имеют нулевую толщину. Оборот — FR4 без маски с печатной
памяткой. Суммарная номинальная толщина 1,52 мм включает лицевую маску.
STEP содержит твёрдые тела сердцевины и фольги, поэтому его измеренная
толщина составляет 1,51 мм; 0,01 мм маски он не экспортирует. Для крепёжной
цепочки используется номинал 1,52 мм с входным контролем реальной толщины.
`audit/v2_shield_stackup.json` фиксирует эти величины отдельно.

F.Cu — одна связная область GND с отступом 0,30 мм от края и от стенки
четырёх NPTH Ø3,20 мм. Центры: (3,5;3,5), (86,5;3,5), (3,5;56,5),
(86,5;56,5) мм. Открытие F.Mask Ø6 мм у каждого отверстия создаёт контакт
металлической шайбы с фольгой. Внутренний диаметр меди вокруг отверстия —
Ø3,80 мм. Полигон настроен `NEVER` для удаления островков; скрытый
`GF1` — только якорь присвоения GND сплошной меди, без отверстия маски/пасты,
не электронная деталь и не позиция закупки. В заполненной фольге пять вырезов:
четыре зазора крепежа и один общий зазор массива межплатных штырей.

HS1 содержит **12 отдельных NPTH Ø2,00 мм**, расположенных сеткой 2×6
с шагом 2,54 мм. В native координатах экрана столбцы X = 64,15…76,85 мм,
ряды Y = 49,00 и 51,54 мм. После сборочного переворота X180 они совпадают
с фактическими штырями J101 на POWER: X = 64,15…76,85 мм,
ряды Y = 11,00 и 8,46 мм. Сопоставление выполняется по каждому из двенадцати
контактов; кабеля между платами больше нет. Контакты 1/3/5 — FILTER_OUT,
2/4/6/8 — GND, 7 — SYS_3V3 для питания INA219 от LOGIC, 9 — напряжение BAT,
10 — SDA, 11 — MODE, 12 — SCL. Возврат питания и сигналов проходит по
контактам разъёма; крепёж обеспечивает контакт фольги экрана с землёй.

Минимальный зазор от стенки отверстия HS1 до фольги — 0,50 мм, то есть
эквивалентный диаметр медного зазора отдельного отверстия — Ø3,00 мм.
Зазоры соседних отверстий пересекаются; чтобы между ними не оставались
плавающие ромбовидные островки меди, у всего массива задан **общий вырез
только в полигоне**: X = 62,65…78,35 мм, Y = 47,50…53,04 мм.
FR4 в этом прямоугольнике сохраняется. Физической прорези нет; между
соседними отверстиями остаётся номинальная перемычка FR4 0,54 мм.

Для выбранной пары AliExpress длина металлического штыря составляет 35 мм,
включая хвост пайки 3 мм; высота кончика над POWER — 32 мм. Розетка H8,5
на LOGIC даёт номинальный ввод 4,48 мм при расстоянии между рабочими
поверхностями плат 36,02 мм. Стойки и шайбы сохраняются. Сечение штыря,
его прямолинейность и допустимый ввод этой универсальной пары продавцом
полностью не нормированы, поэтому механическое и электрическое сопряжение
проверяют на реальных образцах до выпуска плат.

Условия входного контроля прохода через HS1: фактический диаметр отверстия
не меньше 1,95 мм, диагональ штыря не больше 0,94 мм, относительное смещение
осей плат не больше 0,25 мм, боковое отклонение штыря у экрана не больше
0,15 мм. Это проектные условия приёмки, а не заявленные допуски продавца.
Их сочетание оставляет минимум 0,105 мм механического зазора до стенки
отверстия. Если образцы не выдерживают эти условия, сопряжение и сверловку
нужно уточнить по измерениям. Каждый штырь должен проходить свободно;
силовой посадки и контакта с фольгой экрана быть не должно.

Надписи находятся только на F.SilkS/B.SilkS. На обеих сторонах есть краткая
памятка: назначение этажей, питание, межплатные контакты, J11/USB и сборочные
варианты. Значения R3/R4/C30/R15/R16/R56 прочитаны непосредственно из текущей
таблицы `baseline/S4_16/assembly_variants_S4_16.csv`. Медные буквы и физические
прорези отсутствуют; описанный общий вырез относится только к фольге.
Обратная маркировка ориентирована для вида сверху после
сборочного переворота X180; обычный native вид снизу поэтому повёрнут на 180°.
Читаемый сборочный вид — `output/SHIELD/MeshRepeater2_Shield_assembly_top.svg`.

Крепёж: четыре нижние стойки RUICHI PCHSN-18 (18 мм), четыре верхние Connfly
H-L1500-2100-5-03-1N1W (15 мм), 20 металлических шайб DIN433
3,2 × 6 × 0,5 мм. Порядок снизу: гайка → шайба → POWER → стойка18 → шайба
→ экран медью вниз → шайба → стойка15 → шайба → LOGIC → шайба → винт M3×6.
Шайбы экрана должны прижимать чистые контактные области; изолирующие шайбы
здесь неприменимы. Номинальные межэтажные зазоры 18,5 и 16 мм. Реальную длину
шпилек, глубину резьбы и прижим проверяют при сборке, как указано в общей
механической документации.

Локальная библиотека `Shield.pretty` содержит крепёжные отверстия,
механический массив HS1 и скрытый якорь фольги. Для экрана схемы и ERC не
требуются. Native DRC выполняется
без парности со схемой, со всеми включёнными правилами и без исключений.
`audit/v2_shield_foil_audit.json` проверяет точный файл, одну медную область,
ровно пять вырезов в меди, двенадцать отдельных отверстий HS1 и непрерывность
каждого из четырёх контактных колец. Сам HS1 не является устанавливаемой
деталью и исключён из BOM/координат монтажа. Финальная проверка физических
координат связывается с SHA-256 сохранённых POWER/LOGIC/SHIELD.
Native SVG/PNG и STEP находятся в `output/SHIELD`.

Повторная генерация:

```powershell
& 'C:/Program Files/KiCad/10.0/bin/python.exe' tools/cad/build_v2_shield.py
& 'C:/Users/Alksndr/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe' tools/cad/render_native_svg_png.cjs output/SHIELD
```
