# Mesh Repeater v1.26

Одноплатное ведущее исполнение 90×100 мм.

[Готовый комплект ZIP](https://github.com/Alksndr55/mesh-repeater/releases/download/v1.26/Mesh_Repeater_v1.26_KiCad.zip) · [Страница выпуска](https://github.com/Alksndr55/mesh-repeater/releases/tag/v1.26)

## Открытие и сборка

Полностью распакуйте ZIP в обычную папку и запустите [START.cmd](START.cmd). Portable NexusBV 0.9 для Windows 10/11 x64 включён; установка и ассоциации файлов не нужны. Меню выбирает плату и сборку, затем открывает соответствующие CAD и PDF по относительным путям.

В комплекте **2 boardview CAD**: по два для каждой физической платы — `NaIon_COLD` и `LTO_2S`. В CAD указаны номиналы и DNP выбранной сборки; площадки неустанавливаемых деталей сохранены. Для перехода со схемы дважды щёлкните по свободной части тела символа или его обозначению в PDF внутри NexusBV. Видимый текст внутри символа сохраняет свой поиск.

Для редактирования откройте проект платы в **KiCad 10**. Все используемые посадочные места и 3D-модели включены в проект и используют относительные пути; отдельная установка стандартных 3D-библиотек не требуется. Сохраняйте структуру распакованного комплекта. В 3D-просмотре включите категории моделей SMD и выводных компонентов.

- [MAIN](v1/design/Meshcore_NaIon/Meshcore_NaIon.kicad_pro)

Общая электрическая схема: [KiCad](shared/schematic/MeshRepeater.kicad_pro), [PDF](shared/output/pdf/MeshRepeater_schematic.pdf). У общей схемы нет отдельной PCB; физические платы перечислены выше.

## Изменения 06.11.2026

- R31 приведён к 100 кОм. C13 переведён на 0805; C13/C60/C62 используют общий 100 нФ / 50 В / X7R. Число уникальных артикулов R/C во всех вариантах уменьшено с 44 до 42. Точные делители, силовые шунты и входные R72/R73 INA219 по 10 Ом сохранены.
- Площадки L2 расширены наружу на 0,5 мм с каждой стороны для ручной пайки; внутренний зазор и окна пасты сохранены. Номинал — 0,47 мкГн. Совместимость неизвестного донорского дросселя этим не подтверждается.
- Разъём GPS J4 смещён на 2 мм вглубь платы, L4 — на 1,5 мм вправо. Подводы адаптированы; RF и Kelvin-геометрия сохранены.
- Улучшены обозначения деталей и разъёмов, ключ U7, подписи USER/RESET; R37 выделен рамкой W_RESET. Для R56 указаны все три варианта: Na-ion с COLD — 1,8 Ом; Na-ion без COLD — 0 Ом; LTO 2S — 0 Ом.
- Проверены фактические термобарьеры C22/C23/C59, устранены найденные острые ответвления. Земляные переходы восстановлены после изменения трасс по правилам сетки 5 мм; исключения записаны в `routing_review.json` каждой платы.
- Используемые стандартные 3D-модели включены в каждый проект вместе с лицензиями и сведениями об источниках. Готовые архивы проверены после распаковки с отключённым глобальным каталогом моделей KiCad.

R31 с C26=100 нФ задаёт постоянную времени около 10 мс вместо 1 мс; отпускание USER и debounce следует проверить на используемой прошивке. Номиналы, Fit/DNP и условия сборки приведены в [общей инструкции](docs/ASSEMBLY_COMMON_RU.md) и [BOM](v1/bom/COMPONENT_BOM.csv).

Watchdog **v1.00** включён в [v1/design/watchdog_reference](v1/design/watchdog_reference); исходники и HEX соответствуют [канонической прошивке](https://github.com/Alksndr55/watchdog/releases/tag/v1.00). Перед ISP снимают R37. Запись flash и fuse выполняется отдельно; подробности — в `INTEGRATION_RU.txt`.
