# Mesh Repeater 2.0

Этот рабочий каталог относится к версии 2.0 и Git-ветке `mesh-repeater-2.0`.
Версии 1.0 и 2.0 ведутся параллельно.

- Вносить изменения версии 2.0 только внутри этого рабочего каталога.
- Основная версия 1.0 находится в `Meshcore/v1`; опубликованный снимок —
  в `Meshcore/release/mesh-repeater`. Не менять их в рамках работы над 2.0
  без указания пользователя.
- Рабочая папка версии 2.0 — обычный каталог `Meshcore/v2` и зарегистрированный
  Git-worktree репозитория `Meshcore/release/mesh-repeater`.
  Не создавать независимый дубликат и не перемещать worktree обычными файловыми командами.
- Унаследованные файлы 1.0 перенесены в локальный `archive/v1_S4_16`.
  Для проверок 2.0 использовать `baseline/S4_16` и `audit/source_s4_16`,
  не читать рабочую версию 1.0 или архивную копию как текущую зависимость.
- Исходная S4.16 — база, а не проверенная версия 2.0. Старые проверки и
  контрольные суммы не использовать как подтверждение новых изменений.
- Перед использованием общего инженерного скрипта проверить его пути
  входных и выходных файлов; для 2.0 сделать отдельную копию и настроить
  её на этот каталог.
- Следовать заданию docs/Mesh_repeater_v2_Codex_prompt_RU.txt и последующим
  уточнениям пользователя. Сохранять функциональные связи, номиналы и GPIO S4.16;
  разрешены новое разбиение, механика и трассировка. J10 остаётся на исходном
  месте, доступ к ISP после разборки; изменений для внешнего доступа не требуется.
- Общаться обычным ясным языком. Caveman включать только по прямому запросу.
